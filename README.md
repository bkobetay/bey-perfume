# BEY Perfume — локальная демоверсия

Первый этап: адаптивная главная страница по тёмному референсу. Чистые HTML, CSS и JavaScript, без устанавливаемых зависимостей и внешних запросов при просмотре.

## Запуск на Mac

Требуется Node.js 20 или новее.

```sh
cd /Users/alpha/Documents/ChatGPT/bey-perfume
npm --prefix site run dev
```

Открыть http://127.0.0.1:4173/. Сервер доступен только на этом компьютере. Остановка — Ctrl+C в терминале, где запущен сервер. Изменения видны после обновления страницы.

Если порт занят, используйте `PORT=4174 npm --prefix site run dev`.

## Что сделано

- Первый экран с брендовой иллюстрацией флакона, слоганом и переходами к разделам.
- Основа каталога: шесть направлений и описание характерных нот. Это не ассортимент магазина.
- Разделы «Выбор BEY», «О магазине» и футер.
- Мобильное меню, якорные ссылки, управление вкладками стрелками, Home и End, закрытие меню Escape.
- Видимый фокус клавиатуры, ссылка пропуска навигации и поддержка уменьшенного движения.

В этом этапе нет товарных карточек, отдельных страниц ароматов, цен, корзины, заказа, оплаты, формы подбора и видеоплеера. Не добавлены неподтверждённые контакты и коммерческие обещания. Направления ароматов и тексты — демонстрационный материал, который нужно согласовать с магазином.

Изображение флакона создано Imagegen специально для демо и не является фотографией реального товара. Хранится локально в WebP. Внешние шрифты, аналитика и сторонние сервисы не используются.

## Файлы

- `site/dist/index.html` — структура и тексты.
- `site/dist/styles.css` — оформление и адаптация.
- `site/dist/app.js` — направления ароматов, меню, активная навигация.
- `site/dist/assets/` — иллюстрация и иконка.
- `site/scripts/serve.mjs` — локальный сервер.
- `docs/CHANGELOG.md` — изменения по этапам.
- `docs/QA.md` — выполненные проверки и ограничения.

## Проверка и история

```sh
npm --prefix site run check
git show --stat
git show -- site/dist/index.html site/dist/styles.css site/dist/app.js
```

`check` проверяет синтаксис JavaScript. Поведение и внешний вид дополнительно проверяются в браузере; результаты первого этапа записаны в `docs/QA.md`.

Изменения сохраняются в локальном Git. Деплой и отправка в GitHub не выполнялись.
