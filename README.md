# BEY Perfume — локальная демоверсия

Адаптивная главная страница и отдельный каталог по тёмному референсу: HTML, CSS и JavaScript. Приложение работает без установки зависимостей и без внешних запросов при просмотре.

## Запуск на Mac

Требуется Node.js 20 или новее.

```sh
cd /Users/alpha/Documents/ChatGPT/bey-perfume
npm --prefix site run dev
```

Открыть http://127.0.0.1:4173/. Сервер доступен только на этом компьютере. Остановка — Ctrl+C. Изменения видны после обновления страницы. Если порт занят: `PORT=4174 npm --prefix site run dev`.

## Что сделано

- Первый экран с иллюстрацией BEY, янтарной кнопкой и реакцией света на курсор.
- Отдельный каталог `/catalog.html`: восемь ароматов, «Все» и шесть направлений, поиск по названию/бренду/нотам, счётчик и страницы по 12 товаров. Фильтры, поиск и номер страницы сохраняются в URL.
- На главной — компактный переход в каталог; рост ассортимента не увеличивает длину главной страницы.
- «Выбор BEY»: четыре парфюма с подъёмом флаконов, мягким наклоном карточек и бликом.
- «Обзоры от ALISH»: три превью будущих Instagram-обзоров, отдельный пункт меню. На телефоне лента листается по горизонтали.
- Значки Instagram и TikTok в шапке и футере обеих страниц ведут на профили BEY Perfume, указанные пользователем.
- Стеклянное меню, локальный Manrope, адаптивная сетка, плавная навигация.
- Клавиатура, видимый фокус, reduced motion; каталог виден и без JavaScript.

Цены, корзина, оформление заказа и отдельные страницы товаров пока не добавлены. Видео ещё не подключены. Mawashi и Montacabo показаны с условными флаконами; до уточнения брендов они присутствуют во вкладке «Все» без выдуманных характеристик. Источники остальных нот, фотографии и оговорка о редакции Gaba — в `docs/CATALOG-SOURCES.md`.

## Изменение ассортимента

Единый список: `site/data/products.json`. Поля `categories` управляют фильтрацией, `featured` — попаданием в «Выбор BEY». На главной показываются только первые четыре отмеченных аромата; весь ассортимент находится в каталоге. После изменения списка обновить статические карточки:

```sh
npm --prefix site run catalog
npm --prefix site run check
```

`index.html` и `catalog.html` уже содержат готовые карточки: генератор не требуется для запуска сервера. Названия и ноты экранируются, повторяющиеся ID, неизвестные категории и отсутствующие изображения вызывают ошибку генерации.

## Файлы

- `site/dist/index.html` — главная страница, компактный переход и четыре карточки между комментариями `selection`.
- `site/dist/catalog.html` — отдельный каталог с карточками между комментариями `catalog`.
- `site/dist/styles.css` — оформление и адаптация.
- `site/dist/app.js` — общее меню и якорная навигация.
- `site/dist/catalog.js` — фильтры, поиск, пагинация и состояние каталога в URL.
- `site/dist/motion.js` — декоративные реакции на курсор; выключены на touch и при reduced motion.
- `site/dist/assets/` — локальные изображения и Manrope с лицензией SIL OFL.
- `site/scripts/catalog.mjs` — генератор карточек из списка.
- `site/scripts/serve.mjs` — локальный сервер.
- `docs/CHANGELOG.md`, `docs/QA.md` — изменения и результаты проверок.

## Сохранения в GitHub и откат

Репозиторий: https://github.com/bkobetay/bey-perfume. Локальная ветка `codex/homepage-skeleton` отправляется в `origin/main`.

После каждого завершённого изменения: проверка → коммит → автоматический push. Версионируемые hooks лежат в `.githooks/`; post-commit отправляет коммит и достижимые аннотированные теги, pre-push проверяет синтаксис JavaScript. Это отправка исходников; сайт по-прежнему запускается локально.

Для включения hooks в новом клоне:

```sh
git config --local core.hooksPath .githooks
```

Для первой авторизации Git на Mac используется `gh auth login --hostname github.com --git-protocol https --web`, затем `gh auth setup-git`. Токены не записываются в проект. Если сети или авторизации нет, коммит остаётся локально и hook явно сообщает, что push не состоялся. После устранения причины повторить `git push --follow-tags`; проверить `git status -sb` и удалённый SHA.

История:

Состояние до каталога: тег `checkpoint/v3-before-product-catalog`, коммит `39c7722`. Состояние после этапа: `checkpoint/v4-product-catalog`. До выделения отдельного каталога: `checkpoint/v4-before-separate-catalog`. После: `checkpoint/v5-separate-catalog`.

```sh
git log --oneline
git diff checkpoint/v3-before-product-catalog checkpoint/v4-product-catalog --stat
git diff checkpoint/v3-before-product-catalog checkpoint/v4-product-catalog -- site/dist/app.js
```

Чтобы посмотреть предыдущую версию без удаления новой, при чистом рабочем дереве создать отдельную ветку:

```sh
git switch -c codex/review-v3 checkpoint/v3-before-product-catalog
```

Вернуться к текущей версии: `git switch codex/homepage-skeleton`. Обновить страницу браузера после переключения. Патчи и скриншоты хранятся локально в `artifacts/`; исходники каждого завершённого этапа сохранены коммитом.
