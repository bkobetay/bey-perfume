# ARAFAN Perfume

Магазин разливной парфюмерии и оригинальных ароматов на распив. Витрина: HTML/CSS/JavaScript, локальный сервер Node.js + SQLite; облачная версия Cloudflare Pages + D1. Фотографии и шрифты обслуживаются локально, просмотр каталога не обращается к сторонним поставщикам изображений.

## Запуск

Требуются Node.js 22.18+ и Python 3 для повторной генерации страниц.

```sh
npm --prefix site run admin:setup
npm --prefix site run dev
```

Витрина: http://127.0.0.1:4173/. Кабинет продавца запускается отдельной командой `npm --prefix site run admin` на http://127.0.0.1:4174/. Пароль хранится только в игнорируемом `site/private/admin-access.txt`. Для другого порта используйте `PORT=4185 ADMIN_PORT=4186`. `BEY_PRIVATE_DIR` позволяет изолировать тестовую базу.

## Текущие возможности

- Отдельные страницы главной, каталога разлива, распива, наборов, акций, оптовиков, магазина, контактов, доставки и личного кабинета.
- 190 позиций из прайсов владельца: 189 разлива и подтверждённый OF-001 на распив. Коды и цены за миллилитр сохранены. Поиск по коду, бренду, названию и нотам, четыре категории исходных прайсов, страницы по 12 товаров.
- Объёмы 5, 10, 20, 30 мл; сервер самостоятельно рассчитывает цены и проверяет наличие. Карточка содержит фото, описание, ноты, бренд, аудиторию, формат и артикул.
- Оценки стойкости и шлейфа из таблиц владельца для 190 позиций, круговые диаграммы. W-044 удалён по прямому указанию владельца.
- Избранное в браузере, корзина, изменение количества, гостевое оформление с именем, телефоном +7, адресом и комментарием. Сохранение заявки идемпотентно, повтор запроса не создаёт второй заказ.
- Регистрация и вход по email/паролю, выход, просмотр собственных заказов. Чужие заказы не ищутся по номеру телефона.
- Кабинет продавца: поиск по коду заказа/аромата, имени и телефону, вкладки статусов, заметки, WhatsApp с составом заказа на русском и казахском. Количественный склад удалён из интерфейса и API. Исторические движения сохранены для аудита.
- Продавец меняет бинарное наличие, цену за мл и акционную цену. Версия записи защищает от перезаписи чужих изменений. Завершение таймера скрывает таймер, цена сохраняется до ручной корректировки.
- Информация о магазине из предоставленного DOCX; три страницы сертификата как изображения с перелистыванием и увеличением.
- Навигация по референсу navbar2: компактная округлая панель, меню категорий и брендов, широкий поиск над навигацией и верхняя строка со ссылками о магазине, доставке и контактах; мобильное меню. Компактная консультация открывает WhatsApp с введённым сообщением. Умеренные анимации, клавиатура и reduced motion.

## Источники и редактирование

`site/data/products.json` — ассортимент. `site/scripts/storefront.py` — источник HTML всех страниц. `site/scripts/catalog-enrichment.json` хранит подтверждённые фото, ноты, аудиторию и оценки для повторного импорта. Происхождение данных и исключения: [docs/catalog-import.md](docs/catalog-import.md).

```sh
python3 site/scripts/import-catalog.py /путь/к/прайсам
python3 site/scripts/import-performance.py /путь/к/таблицам
npm --prefix site run catalog
npm --prefix site run check
npm --prefix site test
```

Импорт не изменяет исходные XLSX. Артикул определяет сопоставление; цены не берутся из таблиц характеристик. Изображения оригинальных флаконов в разделе разлива иллюстрируют аромат-ориентир, формат товара указан явно.

## Отдельные следующие этапы

Онлайн-оплата Kaspi отложена по просьбе владельца, отметка «Оплачен» вручную не выставляется. Отправка email для восстановления пароля ещё не настроена; API возвращает понятную ошибку, письмо не имитируется. Для автоматической бесплатной доставки нужны утверждённая зона и геосервис. Переводы на казахский/английский, сезонность, юридические реквизиты и готовые отзывы требуют отдельного наполнения/согласования. Эти возможности не заявляются как уже работающие.

## Сохранения и публикация

Репозиторий: https://github.com/bkobetay/bey-perfume. Ветка `codex/homepage-skeleton` отслеживает `origin/main`. После завершённого изменения: проверки → diff → коммит → автоматический push через `.githooks/post-commit`; факт отправки проверяется отдельно. Без force-push.

```sh
git config --local core.hooksPath .githooks
git log --oneline
git diff checkpoint/v47-navigation-stability HEAD --stat
```

Выкладка выполняется отдельно и только по разрешению пользователя: `npm --prefix site run build:pages`, затем Wrangler Pages deploy из `site/`. Публикуется allowlist-сборка `artifacts/arafan-pages`, а не репозиторий целиком. Приватные базы, пароли, OAuth-настройки, выгрузки и резервные копии не коммитятся и не попадают в публичную сборку. Миграция `0002_retail_accounts.sql` сохраняет старые заказы и журнал склада. До применения миграций требуется приватная резервная копия.

Подробности прежнего развёртывания: [docs/ARAFAN-CLOUDFLARE.md](docs/ARAFAN-CLOUDFLARE.md). Исторические описания старого склада в других документах относятся к предыдущим этапам.
