# BEY Perfume — локальная демоверсия

Адаптивная главная страница по тёмному референсу: HTML, CSS и JavaScript. Приложение работает без установки зависимостей и без внешних запросов при просмотре.

## Запуск на Mac

Требуется Node.js 20 или новее.

```sh
cd /Users/alpha/Documents/ChatGPT/bey-perfume
npm --prefix site run dev
```

Открыть http://127.0.0.1:4173/. Сервер доступен только на этом компьютере. Остановка — Ctrl+C. Изменения видны после обновления страницы. Если порт занят: `PORT=4174 npm --prefix site run dev`.

## Что сделано

- Первый экран с иллюстрацией BEY, янтарной кнопкой и реакцией света на курсор.
- Восемь ароматов: вкладка «Все», шесть направлений, короткие ноты, счётчик результатов и плавная фильтрация.
- «Выбор BEY»: четыре парфюма с подъёмом флаконов, мягким наклоном карточек и бликом.
- «Рекомендации от Альиша»: три превью будущих Instagram-обзоров, отдельный пункт меню. На телефоне лента листается по горизонтали.
- Стеклянное меню, локальный Manrope, адаптивная сетка, плавная навигация.
- Клавиатура, видимый фокус, reduced motion; каталог виден и без JavaScript.

Цены, корзина, оформление заказа и отдельные страницы товаров пока не добавлены. Видео ещё не подключены. Mawashi и Montacabo показаны с условными флаконами; до уточнения брендов они присутствуют во вкладке «Все» без выдуманных характеристик. Источники остальных нот, фотографии и оговорка о редакции Gaba — в `docs/CATALOG-SOURCES.md`.

## Изменение ассортимента

Единый список: `site/data/products.json`. Поля `categories` управляют фильтрацией, `featured` — попаданием в «Выбор BEY». После изменения списка обновить статические карточки:

```sh
npm --prefix site run catalog
npm --prefix site run check
```

`index.html` уже содержит готовые карточки: генератор не требуется для запуска сервера. Названия и ноты экранируются, повторяющиеся ID, неизвестные категории и отсутствующие изображения вызывают ошибку генерации.

## Файлы

- `site/dist/index.html` — разделы страницы и сгенерированные карточки между комментариями `catalog` / `selection`.
- `site/dist/styles.css` — оформление и адаптация.
- `site/dist/app.js` — фильтры, меню, якорная навигация.
- `site/dist/motion.js` — декоративные реакции на курсор; выключены на touch и при reduced motion.
- `site/dist/assets/` — локальные изображения и Manrope с лицензией SIL OFL.
- `site/scripts/catalog.mjs` — генератор карточек из списка.
- `site/scripts/serve.mjs` — локальный сервер.
- `docs/CHANGELOG.md`, `docs/QA.md` — изменения и результаты проверок.

## Локальные сохранения и откат

Состояние до каталога: тег `checkpoint/v3-before-product-catalog`, коммит `39c7722`. Состояние после этапа: `checkpoint/v4-product-catalog`. Никаких push и публикаций.

```sh
git log --oneline
git diff checkpoint/v3-before-product-catalog checkpoint/v4-product-catalog --stat
git diff checkpoint/v3-before-product-catalog checkpoint/v4-product-catalog -- site/dist/app.js
```

Чтобы посмотреть предыдущую версию без удаления новой, при чистом рабочем дереве создать отдельную ветку:

```sh
git switch -c codex/review-v3 checkpoint/v3-before-product-catalog
```

Вернуться к текущей версии: `git switch codex/homepage-skeleton`. Обновить страницу браузера после переключения. Патчи и скриншоты хранятся локально в `artifacts/`; исходники каждого завершённого этапа сохранены коммитом.
