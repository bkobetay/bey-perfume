# Сауле · Золотой квадрат Алматы

Мультяшная игра для одного игрока, с клавиатурой и сенсорным управлением.

Откройте `dist/index.html` в браузере, либо запустите локальный сервер из корня репозитория:

```sh
python3 -m http.server 8765 --directory games/saule-almaty/dist
```

Стрелки / WASD — ходьба. Shift / пробел — бег. Escape — пауза.
Соберите 12 звёзд и посетите памятник Виктору Цою, парк Д. Кунаева и дом-музей М. Ауэзова. После завершения можно продолжить свободную прогулку. Увеличенный персонаж и плашка «Сауле» сохраняют размер при смене масштаба карты.

Карта использует настоящие улицы и контуры зданий из OpenStreetMap: Тулебаева, Кунаева, Кабанбай батыра, Жамбыла, Шевченко, Курмангазы и соседние кварталы. Игровая граница проходит по Медеуской стороне проспекта Назарбаева. «Золотой квадрат» не является официальным административным районом; выбран фрагмент исторического центра и прилегающие кварталы. Карта — двумерная географическая схема, а не фотография или точная модель фасадов. Проход сквозь здания заблокирован. Коллекционные звёзды и точки посещения находятся на ближайших улицах и дорожках; музей отмечен у публичного прохода рядом со зданием.

Геоданные и их производная база `dist/map-data.js`: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Дата снимка базы и границы записаны внутри файла. Производная база распространяется на условиях ODbL; это не меняет лицензию независимого кода и персонажа. Изображение карты построено из этих данных. Персонаж Сауле создан для игры с помощью ImageGen. Шрифты Manrope поставляются со своей лицензией в `dist/assets/FONT-LICENSE.txt`.

`scripts/build-map.py` воспроизводит карту и минимальную базу из Overpass JSON-снимка с геометрией (`out geom`); требуется Python с Pillow:

```sh
python3 games/saule-almaty/scripts/build-map.py /path/to/osm.json
```

Кнопка ♪ открывает официальный YouTube-плеер Ariana Grande — No Tears Left to Cry. Встроенное воспроизведение зависит от доступности YouTube; во время проверки сервис возвращал «Видео недоступно». Песня не скачивается и не включена в дистрибутив. В панели можно выбрать собственный аудиофайл: он воспроизводится по кругу, без загрузки на сервер, на громкости 35%. Кнопка ♪ и закрытие панели останавливают музыку. Повторное открытие возобновляет выбранный файл. После обновления страницы файл нужно выбрать снова.

Карта и игра работают без интернета. Интернет нужен только для внешнего музыкального плеера; при его открытии браузер обращается к YouTube. Игра не сохраняет персональные данные.
