# Сауле · Золотой квадрат Алматы

Мультяшная игра для одного игрока, с клавиатурой и сенсорным управлением.

Откройте `dist/index.html` в браузере, либо запустите локальный сервер из корня репозитория:

```sh
python3 -m http.server 8765 --directory games/saule-almaty/dist
```

Стрелки / WASD — ходьба. Shift / пробел — бег. Escape — пауза.
Соберите 12 звёзд и посетите кофейню, сквер и фонтан. После завершения можно продолжить свободную прогулку.

Карта — художественная интерпретация района, а не географическая схема. Иллюстрации карты и Сауле созданы для игры с помощью ImageGen. Звуковые сигналы синтезируются в браузере и включаются отдельной кнопкой. Игра не передаёт данные и не сохраняет персональную информацию.
