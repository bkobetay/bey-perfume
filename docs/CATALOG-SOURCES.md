Wild Vetiver — самостоятельный аромат; он не заменён на Original Vetiver.

## Два неуточнённых названия

Mawashi и Montacabo сохранены ровно по списку пользователя. Производители не подтверждены; Montacabo не переименован автоматически в Montabaco. Вкладка «Все» показывает обе позиции. До уточнения им не назначены выдуманные ноты и фильтры. Вместо упаковки неизвестного производителя показан условный CSS-флакон с подписью «Демо-визуал».
