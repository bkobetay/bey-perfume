# Arafan Perfume: Cloudflare Pages

## Оформление

Возвращён Arafan Perfume: предоставленный владельцем логотип, исходный Arafan-флакон из checkpoint `cd00612`, нейтральная предметная фотография знакомства. Основной фон #00291f, глубокие зелёные поверхности и золотой акцент #d8b566. Заголовок — локальный Unbounded Variable 650; остальной интерфейс — Manrope Variable. Обе лицензии шрифтов находятся рядом с файлами.

## Локальная версия

`npm --prefix site run dev` и `npm --prefix site run admin` сохраняют существующую SQLite-базу в игнорируемой `site/private/`. Node.js 22.18+. Локальные данные и учётные записи не загружаются в Cloudflare. Перед очисткой заказов 22 октября 2026 сохранена приватная копия. По прямому запросу владельца удалены 10 заказов и связанные записи; у всех 15 ароматов установлено 100 мл. История до очистки доступна только в резервной копии.

## Облачная версия

- Проект Pages `arafan-perfume`, production branch `main`, адрес `https://arafan-perfume.pages.dev`.
- Только `artifacts/arafan-pages` отправляется в Pages. Сборка: `npm --prefix site run build:pages`.
- `_worker.js` — Advanced mode Pages Functions; D1 binding `DB` содержит отдельные заказы/остатки. SQLite-файлы, резервные копии и локальные клиенты не импортируются.
- SQL-миграции: `site/cloudflare/migrations/`. Новая база получила 15 начальных остатков по 100 мл. Seed использует INSERT OR IGNORE: повторная загрузка не сбрасывает существующий склад.
- Создание приватного доступа: `npm --prefix site run cloud:setup`. Генерирует отдельный случайный пароль, PBKDF2-хеш, случайный путь кабинета и ключ ограничения запросов. Файлы только в `site/private/cloudflare/` с правами 0600. Облачная и локальная конфигурации входа хранятся раздельно; текущее значение пароля задаёт владелец.
- Вход в облачный кабинет — по индивидуальной ссылке из приватного `admin-access.txt`, без публичного пункта меню. Случайный путь дополняет пароль, но не заменяет авторизацию API. Сессии HttpOnly/Secure/SameSite=Strict, срок 8 часов; пароль хранится как PBKDF2 SHA-256, 100000 итераций. Межсайтовые изменения запрещены проверкой Origin, вход ограничен по IP.
- Подтверждение оплаты/списание и ручной возврат выполняются SQL-триггерами в одной атомарной операции. Версии записей предотвращают перезапись чужих изменений; ключи запросов предотвращают дубли.

## Повторная публикация

Wrangler требует OAuth scopes account:read, user:read, pages:write, d1:write. Токены хранит сам Wrangler вне репозитория.

1. Выполнить проверки и сборку.
2. Из каталога `site/`: `npx wrangler d1 migrations apply DB --remote` при появлении новых миграций.
3. При первом запуске загрузить сгенерированные секреты: `npx wrangler pages secret bulk private/cloudflare/secrets.json --project-name arafan-perfume`.
4. Из `site/`: `npx wrangler pages deploy ../artifacts/arafan-pages --project-name arafan-perfume --branch main`.
5. Проверить HTTPS, каталог, API, вход и отсутствие доступа к приватным путям. История Git и история деплоев независимы; push сам по себе не публикует сайт.

Для локальной проверки Cloudflare: скопировать приватный `.dev.vars` в игнорируемый `site/.dev.vars`, применить миграции и seed с `--local`, запустить `wrangler pages dev`. После проверки удалить временный `site/.dev.vars`. Эмулятор использует отдельную базу.

Бесплатные лимиты Pages Functions и D1 действуют по тарифу аккаунта. Платные услуги и домены не подключались. Цены, стартовые остатки, фотографии и права использования бренда должен подтвердить владелец перед реальными продажами. Онлайн-оплата, доставка через службы и уведомления продавцу не интегрированы; продавец обрабатывает заявки в кабинете.

Документация платформы: https://developers.cloudflare.com/pages/functions/advanced-mode/ и https://developers.cloudflare.com/pages/functions/bindings/.
