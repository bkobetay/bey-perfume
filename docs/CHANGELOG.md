# История изменений

## 2026-09-29 — автоматическая отправка коммитов в GitHub

По новой просьбе пользователя отменено прежнее ограничение «только локальные коммиты». Подключён `bkobetay/bey-perfume`, локальная ветка `codex/homepage-skeleton` отслеживает `origin/main`.

- Добавлены версионируемые hooks: автоматический push после коммита и проверка JavaScript перед отправкой.
- При незакоммиченных изменениях в `site/` отправка блокируется, чтобы проверка соответствовала зафиксированному коду.
- При ошибке сети или авторизации локальный коммит сохраняется; hook явно сообщает, что GitHub ещё не обновлён.
- Достижимые аннотированные checkpoint-теги отправляются вместе с коммитами; force-push не используется.
- Рабочее правило сохранено в `AGENTS.md`, инструкция — в README. GitHub CLI установлен через Homebrew для однократного входа Git на Mac.
- Механизм проверен на изолированном локальном bare-репозитории. Вход GitHub CLI подтверждён пользователем; вся начальная история и оба checkpoint-тега отправлены в GitHub. Совпадение удалённого и локального SHA проверено.

## 2026-09-29 — этап 3: реакции на курсор и янтарный свет

Из предоставленного промпта выбраны идеи света внутри кнопки, пространственной глубины и последовательного раскрытия заголовка. Они адаптированы к тёмному оформлению BEY и существующей структуре страницы.

- Главная кнопка получила тёплый янтарный градиент у нижнего края, ограниченный её скруглением, и световой отклик на курсор.
- На первом экране флакон смещается до 6 px по горизонтали и 4 px по вертикали; свет мягко реагирует на положение мыши.
- Фотоблоки наклоняются не более чем на 3°; блик следует за курсором, рамка и подпись мягко подсвечиваются.
- Изображения направления и ритуала слегка приближаются при наведении.
- Строки заголовка последовательно появляются снизу. Появление секций использует отдельное свойство `translate`, чтобы не конфликтовать с наклоном карточек.
- Движение включается только для точного указателя с наведением. На сенсорном вводе оно отключено; `prefers-reduced-motion` оставляет статичный вариант, включая изменение настройки во время просмотра.
- Эффекты сбрасываются при уходе курсора, потере фокуса, смене размеров окна или скрытии вкладки. Постоянного цикла анимации нет: обновления выполняются только при движении указателя.

### Файлы

- `site/dist/motion.js` — изолированная логика декоративных реакций.
- `site/dist/styles.css` — янтарная кнопка, свет, глубина и статичные состояния.
- `site/dist/index.html` — слои первого экрана и строки заголовка.
- `site/dist/app.js` — совместимость появления секций с наклоном.
- `site/package.json` — проверка синтаксиса нового файла.

Полный diff этапа: `artifacts/03-pointer-motion.patch`. Коммит локальный; публикации и push нет.
