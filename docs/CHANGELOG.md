- Фотоблоки наклоняются не более чем на 3°; блик следует за курсором, рамка и подпись мягко подсвечиваются.
- Изображения направления и ритуала слегка приближаются при наведении.
- Строки заголовка последовательно появляются снизу. Появление секций использует отдельное свойство `translate`, чтобы не конфликтовать с наклоном карточек.
- Движение включается только для точного указателя с наведением. На сенсорном вводе оно отключено; `prefers-reduced-motion` оставляет статичный вариант, включая изменение настройки во время просмотра.
- Эффекты сбрасываются при уходе курсора, потере фокуса, смене размеров окна или скрытии вкладки. Постоянного цикла анимации нет: обновления выполняются только при движении указателя.
